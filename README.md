# Ashen-Caverns

Ashen Caverns is a game in development by 3 Colombian Students with the idea of submitting it to Hack Club's Terra, but also with the dream of creating a great game that could be published in the future.


The game takes inspiration in a lot of strangue things, like other games like Terraria and R.E.P.O. Also a very bloody period of our word; the Crusades.

## general Information

-The game is going to have 2D/ Pixel art graffics and art. 
-The game is planned to be a 4 player game, with each player having their own classes. As of right nowm only two classes have been thought and those are a Priest and a Tenplar knight.
